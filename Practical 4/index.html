The chosen theme ('light' or 'dark') is saved to the browser's localStorage API using localStorage.setItem('studenthub_theme', theme). When the DOM loads, an initial script reads this value and sets the data-theme attribute on the <body> before user interaction occurs.

We attach standard ES6 event listeners with addEventListener('click', handler) and addEventListener('keydown', handler). DOM nodes are selected using document.getElementById(), document.querySelector(), and document.querySelectorAll(). Classes are toggled using classList.toggle(), classList.add(), and classList.remove().

The modal dialog has role="dialog" and aria-modal="true". When opened, focus shifts to the modal close button. Pressing the Escape key closes the modal immediately. When closed, focus returns gracefully to the trigger element that opened it.

Inline attributes mix HTML markup with presentation logic, violate Content Security Policy (CSP) best practices, and hinder unit testing. Using external scripts with addEventListener ensures clean separation of concerns and maintainable code.
